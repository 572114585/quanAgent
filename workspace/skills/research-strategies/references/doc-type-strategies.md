# 文档类型详细检索策略

本文档对 4 种文档类型展开详细检索策略。research-agent 子 agent 在需要时查阅。

## 1. 产品介绍（product_brief）

### 默认深度：standard

### 典型维度

| 维度 | 说明 | 关键词模板 |
|---|---|---|
| 核心功能 | 产品能做什么 | `{产品名} 功能 特性` |
| 定价 | 价格体系 | `{产品名} 定价 价格 收费` |
| 优劣势 | 优点和缺点 | `{产品名} 优缺点 评价 评测` |
| 竞品对比 | 与同类产品对比 | `{产品名} vs 对比 替代` |
| 使用场景 | 适用人群和场景 | `{产品名} 适用 场景 用例` |

### 来源偏好

1. **官方资料**（最高优先）：官网、官方文档、官方博客
2. **用户评价**：第三方评测、用户社区、Reddit/V2EX 讨论
3. **竞品对比**：行业对比文章、选型指南

### 来源黑名单

- 纯营销软文（无实质内容，只有宣传语）
- 过时信息（产品已更新，2 年前的评测可能不准确）

### Review 检查清单

- [ ] 核心功能是否覆盖？
- [ ] 定价信息是否有来源？
- [ ] 是否有竞品对比？
- [ ] 来源是否包含官方资料？

## 2. 技术调研（tech_research）

### 默认深度：in-depth

### 典型维度

| 维度 | 说明 | 关键词模板 |
|---|---|---|
| 技术原理 | 底层原理和设计思想 | `{技术名} 原理 架构 设计` |
| 主流框架 | 有哪些实现/框架 | `{技术名} 框架 库 工具` |
| 对比分析 | 各方案优劣势对比 | `{技术名} 对比 性能 benchmark` |
| 落地场景 | 实际应用案例 | `{技术名} 应用 场景 案例 落地` |
| 学术论文 | 前沿研究 | `{技术名} paper 论文 arxiv` |
| 社区生态 | 活跃度、贡献者、趋势 | `{技术名} github star 社区 生态` |

### 来源偏好

1. **官方文档**（最高优先）：技术官网、官方文档、API 文档
2. **学术论文**：arXiv、Google Scholar、会议论文
3. **技术博客**：工程师博客、技术社区（Medium、InfoQ、掘金）
4. **代码仓库**：GitHub README、Issue 讨论、Release Notes

### 来源黑名单

- 营销内容（不含技术细节的公关稿）
- 二手转载（找不到原始出处的转载文章）
- 过时教程（技术已大版本更新）

### 交叉验证要求

- 关键性能数据：≥2 个独立来源验证
- 技术结论：≥2 个独立来源佐证
- 版本信息：以官方文档/Release Notes 为准

### Review 检查清单

- [ ] 技术原理是否有官方文档来源？
- [ ] 性能数据是否交叉验证？
- [ ] 是否覆盖主流框架对比？
- [ ] 是否有学术/前沿研究？
- [ ] 来源中营销内容占比是否过高？

## 3. 新闻日报（news_daily）

### 默认深度：brief

### 典型维度

| 维度 | 说明 | 关键词模板 |
|---|---|---|
| 头条/重大事件 | 最重要的事件 | `{领域名} 重大 突破 最新` |
| 产品/模型发布 | 新产品发布 | `{领域名} 发布 新品 推出` |
| 融资/收购 | 资本动态 | `{领域名} 融资 收购 投资` |
| 政策/监管 | 政策变化 | `{领域名} 政策 监管 法规` |
| 开源项目 | 值得关注的项目 | `{领域名} 开源 github 新项目` |

### 来源偏好

1. **一手报道**（最高优先）：原始新闻源、官方公告
2. **近 7 天资讯**：时效性 > 深度
3. **行业媒体**：专业媒体报道

### 搜索特殊要求

- **必须用 topic="news"**：`web_search(query="...", topic="news")`
- **query 带年份**：如 `"2026 AI 最新动态"`
- **时效性优先**：近 7 天 > 近 30 天 > 更早

### 来源黑名单

- 超过 30 天的旧闻（除非是持续事件的后续报道）
- 无日期的转载（无法判断时效性）
- 内容农场（批量生成的低质量资讯）

### Review 检查清单

- [ ] 是否用了 topic="news"？
- [ ] 每条新闻是否有明确日期？
- [ ] 是否有一手来源（非纯转载）？
- [ ] 维度覆盖是否完整（3-6 个维度）？

## 4. 数据分析（data_analysis）

### 默认深度：in-depth

### 典型维度

| 维度 | 说明 | 关键词模板 |
|---|---|---|
| 市场规模 | 市场总量和增长 | `{指标名} 市场规模 增长率 数据` |
| 统计数据 | 具体数值 | `{指标名} 统计 数据 报告 2026` |
| 行业趋势 | 发展趋势 | `{指标名} 趋势 预测 展望` |
| 竞争格局 | 市场份额 | `{指标名} 市场份额 排名 格局` |
| 对比数据 | 横向对比 | `{指标名} 对比 同比 环比` |

### 来源偏好

1. **统计报告**（最高优先）：官方统计局、行业协会报告
2. **财报**：上市公司财报、年报
3. **行业数据**：第三方研究机构（IDC、Gartner、艾瑞等）
4. **新闻报道**：带数据的一手报道

### 结构化数据要求

- 每个关键指标：≥3 个独立来源验证
- 优先获取表格/图表形式的数据
- 标注数据年份和来源
- 区分"实测数据"与"预测数据"

### 来源黑名单

- 无数据来源的空泛分析文章
- 引用链断裂（A 引用 B，B 找不到原始数据）
- 过时数据（2 年前的市场预测可能已失效）

### Review 检查清单

- [ ] 关键数据是否有来源？
- [ ] 每个指标是否有 ≥3 个独立来源？
- [ ] 数据是否标注年份？
- [ ] 是否有结构化数据（表格/数字）？
- [ ] 预测数据和实测数据是否区分？
